# 设计说明

## 参考页面观察

参考页面为支付宝 Agent Pay 产品页。抓取数据与截图显示，它的核心视觉特征不是复杂装饰，而是：

1. **暖白或近白底**，用大面积留白建立产品感。
2. **深绿主色** `#0a8a4e`，搭配黑色正文和小面积珊瑚色插画元素。
3. **超大标题**与极短副文案，信息密度低但层级极清楚。
4. **胶囊形导航、按钮与标签**，圆角按交互尺度分级。
5. **网格、轨迹线和圆形几何体**作为叙事图形，而不是装饰性渐变。
6. 动效集中在一次首屏编排和少量状态反馈，不持续打扰阅读。

## 本项目如何转译为博客

博客的第一任务是阅读，因此保留参考页的“安静、克制、有几何记忆点”，但降低首屏的信息密度：

- 首页 Hero 用两行主标题和一个深绿色 Field Note 卡片建立识别度。
- 置顶文章使用整块深绿面板，承担首页唯一的高强度视觉焦点。
- 最新文章采用不对称栅格：第一篇占四列，其余占两列，避免整齐卡片阵列。
- 文章详情页将题图做成可复用的抽象封面：网格、轨道、珊瑚圆点与首字。
- 分类页使用不同色相与几何形变，保持主题区分。
- 后台沿用同一套色板与圆角，但提高管理密度。

## M3E 令牌

```css
:root {
  --bg: #f4f6ef;
  --surface-1: #ffffff;
  --text: #151a16;
  --primary: #0a8a4e;
  --primary-container: #caf6dc;
  --tertiary: #e86f49;
  --tertiary-container: #ffe0d3;
  --r-md: 26px;
  --r-xl: 48px;
  --r-full: 999px;
}
```

- **色调表面**：页面底色、一级表面、二级表面通过明度差建立层级，不依赖重阴影。
- **形状层级**：胶囊用于短交互，大圆角用于内容容器，不规则形状只用于 Hero 和空状态。
- **排版**：中文无衬线高字重标题，正文最大阅读宽度约 68ch，行高约 1.9。
- **动效**：首屏一次性 reveal、阅读进度、目录高亮、评论回复反馈；遵循 `prefers-reduced-motion`。

## 组件映射

| 参考页元素 | 博客转译 |
| --- | --- |
| 顶部胶囊导航 | 站点头部导航，移动端展开为全屏菜单 |
| 超大产品标题 | 首页主标题与文章标题 |
| 产品插画卡片 | Field Note Hero 卡片、抽象文章封面 |
| 轨迹/节点动画 | Hero 轨迹线、阅读进度与目录状态 |
| 深色登录按钮 | 登录 / 工作台胶囊按钮 |
| 大留白产品区 | 阅读优先的文章列表与详情页 |

## 可访问性

- 交互有清晰的键盘焦点样式。
- 正文与背景保持高对比度，深色主题单独定义令牌。
- 图像提供 `alt` 或作为纯装饰隐藏。
- 动效在 `prefers-reduced-motion: reduce` 下关闭。
- 移动端无横向滚动，表单控件保持可触达尺寸。
